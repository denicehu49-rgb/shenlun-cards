# 袁东申论·考前速记

打开 `index.html` 即可阅读。不用安装、不用构建。

打印成 PDF：

1. 用 Chrome 或 Edge 打开 `index.html`。
2. 点页面上的「打印 / 另存 PDF」，或按 `Ctrl+P`。
3. 目标打印机选「另存为 PDF」或「Microsoft Print to PDF」。
4. 纸张 A4，边距选默认。勾选「背景图形」，踩分点的浅底才会印出来。
5. 页脚应出现「袁东申论·考前速记」和页码。导航和按钮不会印上。

首页「考前一页纸」是全部题型的识别信号、步骤和三个踩分点。后面每一种题型另起一页，是展开页。一次打印会把首页和各题型一起打出。
