概括归纳

白鹭

识别：圈出「概括 / 归纳 / 总结 / 概述」。接着确认要素：概括的是问题、原因、影响、做法，还是变化。看字数，决定要点写多细。

步骤：

  1. 审题：任务词 → 要素 → 字数。
  2. 标注每段观点句：首句、尾句、转折后、总结前。
  3. 同义要点合并：不同材料说同一件事，合成一条。
  4. 排序：直接相关，然后间接相关，然后背景铺垫。
  5. 成文：总括句 + 分条。每条是序号 + 核心词 + 具体内容。

踩分：要素和题干一致；观点句四位置；同义才合并；字数紧时先保要点条数，再保每条的具体程度。

骨架：总括句。①核心词：具体内容。②核心词：具体内容。

小马哥

识别：任务词是概括、归纳、总结、概述。先看清范围和字数档（见文末「审题四确认」），再读材料。

步骤：

  1. 一个自然段只有一个核心意思：这段的核心句就是一个要点。
  2. 好几段说同一个核心意思：合并成一个要点。
  3. 全部读完再归类。讲同一件事的句子归到一组。
  4. 用材料自己的顺序把组串起来：时间、轻重，或主体。结构是读出来的。

踩分：能用材料原词就用原词，写成动词加宾语。概括是抓住原句的核心意思。只有字数不够、必须压缩时才换词：先删修饰、留主干，再换词。总括句可以不写。材料说了三件事就写三条。

骨架：［总括句，可省略］①要点（尽量原词）②要点③要点

差异：白鹭规定「总括句 + 分条」，每条要有核心词，并按相关程度排序。小马哥的总括句是可选的，一条往往就是材料核心句；顺序跟材料走，不另排一套相关度。

综合分析

白鹭

识别：题干给一个词、一句话、一个观点或一个现象，要求谈谈理解、看法或认识。核心是「理解」。

步骤：固定三截——是什么 → 为什么 → 怎么办。

  1. 是什么（1到2句）：解释题干里的核心概念，给出总体定性。
  2. 为什么（主体）：从材料抽原因、影响、表现，多角度写。
  3. 怎么办（1到2句）：简要对策，或总结表态。

两种变体：词语理解（谈谈对「××」的理解）先解释词语含义，再展开。观点评价（谈谈对「××」的看法）先表态：赞同、反对或辩证看待，再论证。

骨架：是什么。……。为什么。①…②…。怎么办。……。

小马哥

识别：任务词是分析、理解、评价、谈谈看法。

步骤：

  1. 词语理解：①解释含义（是什么）→ ②多角度展开（为什么）→ ③简要总结或对策（怎么办，不宜多）。
  2. 观点评价：①明确表态 → ②从材料里抽论据 → ③简单总结。

踩分：论据从材料来。立场按笔记原话执行：「是什么→为什么→怎么办」是工具，不是模板。材料只有「为什么」，就不要硬写「怎么办」。

骨架：词语题按「解释 → 展开 → 短总结」；评价题按「表态 → 材料论据 → 短总结」。材料没写到的那一截留空。

差异：白鹭把「是什么 → 为什么 → 怎么办」当作固定框架，怎么办保留1到2句。小马哥原话认定这三截是工具不是模板，材料只有「为什么」就不要硬写「怎么办」；观点评价的第三步他写的是「简单总结」。

对策建议

白鹭

识别：题干出现建议、对策、措施、方案、怎么办。题干写了「不考虑格式」，就是纯粹对策内容题，不套公文格式。

步骤：

  1. 材料里直接有的对策，直接抄。
  2. 材料只是暗示，从问题反推对策。
  3. 每条按「针对问题 → 提出对策 → 说明效果」来写。

踩分：一条对策要答出针对什么问题、具体做什么、谁来做、达到什么效果。三条标准：针对性（对准材料里的具体问题）、可行性（能落地）、具体性（不是空话）。

骨架：①针对（问题），由（谁）做（具体的事），达到（效果）。

小马哥

识别：任务词是对策、建议、措施、方案、怎么办。这里的「方案」是对策题的任务词，不是单独文种。

步骤：

  1. 材料里的直接对策，直接提取。信号词：应、要、必须、需要、可以、建议、推动、加强。
  2. 材料只有问题、没有对策，再反推。笔记里的例子：「缺乏资金」反推成「加大投入，拓宽渠道」。
  3. 核心只写「做什么 + 怎么做」。材料有的就写，没有的不编。

踩分：先抓信号词所在的句子。反推只补材料已经露出的问题，不另编主体和效果。

骨架：①做什么。怎么做：……。

差异：白鹭要求每条写到「谁来做」和「达到什么效果」。小马哥原话是「核心是做什么+怎么做，材料有的就写，没有的不编」。

识别：题干出现具体文种。笔记点名的是：发言稿、提纲、报告、倡议书、建议书、调研报告。

步骤：先分清格式和内容，再填。

  1. 格式分条给分。要素：标题、称谓、正文、落款、日期。
  2. 内容三块：开头（背景 + 目的）、主体（核心内容分条）、结尾（号召或总结）。
  3. 题干写了「不考虑格式」，就只写内容，不套公文格式。应用要点里的原话：说了就纯内容，没说就要格式到位。

步骤：

  1. 先判格式。题干写「不考虑格式要求」，就纯内容。题干没说，格式就要到位。
  2. 格式要素：标题、称谓或主送机关、正文、落款、日期。
  3. 内容：开头（背景引入）→ 主体（核心内容分条）→ 结尾（总结或号召，材料有就写）。

踩分：结尾不是每篇必有。材料里没有总结、也没有号召，这一截就不硬加。

骨架：标题 / 称谓或主送 / 正文（背景 → 分条 → 材料里有的收束）/ 落款 / 日期。

大作文

白鹭 · 24句

识别：题干出现议论文、文章、自拟题目，或「写一篇文章」。

步骤：拆成6段、每段4句，共24句。先对上这一句的功能，再填材料。

  1. 开头段4句：①政治句，引用「十四个坚持」或「八个明确」里相关的一条；②what句，点明主题词在当前背景下的内涵；③why句，写主题词的重要意义；④so句，引出标题、点题。
  2. 两段式开头备用4句：①破题句，点出两个概念的关系，例如「A与B相辅相成」；②why1；③why2；④so+，重申观点。
  3. 过渡段4句，放在第二段或倒数第三段：①反题句，指出当前的问题；②过渡句，用名言承接；③why，写危害或原因；④结题句，作警示。
  4. 对策段4句，放在倒数第二段，也可以不写：①领起句，引用经典名言；②what句，写明对策要解决的问题；③why句，谈危害和必要性；④how句，提出具体对策。
  5. 论述段写2段，每段4句：①so，分论点；②why1理证，选一个哲学原理，简单联系、定性；③why2例证，从材料里串着抄或跳着抄；④so'，重申分论点。
  6. 结尾段4句：①收束句，用诗文收束；②大回归，重申总论点关键词；③小回归，重申分论点关键词；④升华句，展望未来。

踩分：「十四个坚持」选6个、「八个明确」选4个背熟。每篇开头只用最相关的1个，不堆砌。笔记没有列出是哪6个、哪4个。例证从材料来，不编案例，不背范文案例。哲学原理和管理效应分别见文末两张表；效应用来把道理说形象，不代替材料里的例子。

骨架：政治句 → 内涵 → 意义 → 点题。主体两段各是「分论点 → 原理 → 材料 → 重申」。结尾是「诗文 → 总论点 → 分论点 → 展望」。

小马哥 · 材料路径

识别：任务词是议论文、文章、自拟题目。题干若写「观点明确 / 见解深刻」，必须亮明总论点。若写「不拘泥于给定资料」，可以用自身积累；「结合 / 参考给定资料」仍以资料为主。

步骤：

  1. 总论点 = 题干主题词 + 材料的总体方向。
  2. 从材料里提2到3个分论点，是总论点在不同维度或不同主体上的展开。
  3. 标题从总论点压缩而来。
  4. 开头：引出话题，然后亮明总论点。不需政治句，但要扣题。
  5. 主体2到3段：分论点句 + 材料里的案例、数据或专家观点 + 自己用1到2句把论据和论点接上。
  6. 结尾：回扣总论点，再作简洁升华。不需诗句。

踩分：底线是把材料的核心观点用自己的话重新组织一遍。不知道怎么开头，就用「引出话题 + 亮明观点」。阅卷看的是论证。分析只加1到2句，不脱离材料另写一套。

骨架：标题（总论点的压缩）。开头：话题 + 总论点。①分论点。材料论据。……（自己分析）。结尾：回扣总论点，收一句。

差异：白鹭按24句填，开头要政治句，论述段要哲学原理，结尾要诗文。小马哥原话是开头「不需政治句」、结尾「不需诗句」；论据用材料里的案例、数据或专家观点，自己只加1到2句分析。

审题 → 读材料 → 组织答案

1. 审题（30秒到1分钟）。圈出题型词、主题词、限定词。定题型：概括、分析、对策、应用文、大作文。先看字数，决定详略。先想这道题用哪一个框架。

2. 读材料。每段标观点句：首尾句、转折句、总结句。信息分三类：可直接抄的、需要转化的、背景噪音。同类合并，再按重要性排序。

3. 组织答案。概括、分析、对策：总括句 + 分条（序号 + 核心词 + 展开）。应用文：格式框架 + 内容。大作文：24句 + 哲学原理理证 + 管理效应例证 + 材料串抄。

字数：审题第一件事就是看字数。字数少，写核心要点；字数多，再展开细节。

小马哥附录

审题四确认（约1分钟）

1. 任务词定题型。概括、归纳、总结、概述 → 概括归纳。分析、理解、评价、谈谈看法 → 综合分析。对策、建议、措施、方案、怎么办 → 对策建议。提纲、报告、发言稿、倡议书、简报 → 应用文。议论文、文章、自拟题目 → 大作文。

2. 范围。「根据给定资料×」只看资料×。「根据给定资料」看全部。「结合 / 参考给定资料」以给定资料为主，自身积累为辅，大作文常见。

3. 字数档。

  • 100字及以内：极简，只写核心要点，关键词加动宾。
  • 100到200字：每个要点1到2句，不展开细节。
  • 200到400字：要点加简要展开，可以适当举例。
  • 400字以上：完整论证结构。

4. 特殊要求。「有条理 / 条理清晰」必须分条，用序号。「逻辑清晰 / 有逻辑性」分条要有内在顺序。「格式正确 / 不考虑格式」决定应用文要不要格式。「观点明确 / 见解深刻」大作文必须亮出总论点。「不拘泥于给定资料」大作文可以用自身积累。

逐段三问

关键原则：不是「找要点」，是「读懂意思」。脑中先不要套框架。申论材料九成有明确观点句，多数时候不用另做提炼。

  1. 这一段在说什么事？用一句话概括。
  2. 核心观点句是哪一句？看首句、尾句、转折后、总结前。
  3. 这段能不能直接回答题干？能，就标出来准备提取。只是间接相关，就想怎么转化。完全无关才跳过，这种情况很少。

标注：做法、措施，给动词短语画线。效果、影响，用方括号框住结果。问题、困难，圈出消极说法。观点、评价，在旁边标上说话人。

全部读完再归类：同一件事归一组，再按时间、轻重或主体串起来。答案结构在这一步浮现。

材料三原则

  1. 材料里的每句话都有用。背景铺垫告诉你这个问题为什么会出现。申论材料没有废话，也没有行测那种干扰项。
  2. 能用原词就不要换词。材料写「改善家居环境」，就不要改成「提升居住条件」。只有字数不够、必须压缩时才转化：先删修饰词、留主干，再换词概括。
  3. 材料的逻辑就是答案的逻辑。材料按时间写，答案就按时间；按主体写，就按主体；按问题、原因、对策写，就按这个顺序。结构不是另想出来的。

写完检查（约1分钟）

  1. 要点全不全：回到各段标注，看有没有漏掉的核心信息。
  2. 条理清不清：读一遍，分条是否顺，别人能不能看懂。
  3. 字数合不合适：超出，先删修饰词和重复的话，再压次要要点。不足，先查是不是漏了要点。

行政执法申论

材料常常是「法条 + 案例 + 专家点评」三段。法条告诉你该怎么做，案例告诉你实际上做了什么，专家点评告诉你做得怎么样、还有什么问题。

步骤：法条找标准，案例找做法，专家找评价。三者合在一起就是答案。

踩分：考的是申论，不是法学。不用背法条。材料里的法言法语直接抄。
