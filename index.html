袁东申论·考前速记

按空白讲义的题型目录收口。解题步骤、踩分点和口诀来自个人复盘笔记。空白讲义对应位置只有题干和材料，方法没有展开。两边口径不一致时，以笔记为准，页内用「注」标出。

考前一页纸

读材料（概括题每节都复盘这三句）：粗读定逻辑、定前置词；精读定内容、定关键词；再从宏观、中观、微观盘点。

宏观看首尾、高频词、关键词、关联词、主体。中观看总分、分总、总分总、递进、并列。微观选大哥、留高频词、做选词组合。

审题要素顺序：对策、问题、影响、原因、背景现状。一个点又能当对策又能当影响时，字数紧可以不单列。

字数：20分一般5点，少则3、多则7。300字一点约60字，可补做法；40字只写动词加事情。200字以内留动词加事情；200到250字留总括，删故事。40字以内合并动词。超字数先删修饰，保核心点。

缩写五刀：留动词加事情；故事和总括都有就留总括；三级目录留一、二级；同义动词合并；保大弃小，留规范表述，丢微观例子。

概括对策 展开

认出：概括主要做法、主要措施。问的是动词加事件。完成时、现在时才写。

  1. 审题定范围、主体、字数，划掉“将、未来、接下来”。
  2. 粗读：首尾和高频词定总括，标出总与分。
  3. 精读：有规范表述用原词；没有就从故事里抽动词加事情。
  4. 并列做法不要硬挑一个当总括；选不出大哥，用问题反推，或看出现两次以上的高频词。
  5. 一条一个点：总括词加做法。例子、单个点位、影响结果不进答案。
  1. 一个都不少，宁滥勿缺，按词得分。
  2. 原词原句优先；不规范才转成规范说法。
  3. 要点写成前置词，每条独立呈现。

概括问题 展开

认出：乱象、问题、不足、简述负面情况。要消极表述。

  1. 开头若是正面愿景，多半是背景，不入点。
  2. 只收问题本身：制作粗糙、维权无门、盗版抄袭这类消极事实。
  3. 监管部门的对策、后来的成效，不是乱象。
  4. 故事前后交叉时，看是不是同一个问题，不能顺手并成一点。
  5. 双性结果字数不够可以不写。有规范表述就用规范表述。
  1. 负面、消极，原词优先。
  2. 对策和成效不能充作问题。
  3. 同一问题才合并，不同困难分开写。

概括原因 展开

认出：分析原因、为什么能做成。笔记判断：这类题绝大多数其实在找对策。

  1. 原因收三类：对策（动词）、形容词（长处、条件）、成果影响。
  2. 能直接回答“为什么做成”的句子就代入，往目标上靠。
  3. 既像做法又像结果，只要构成原因就写。
  4. 同一话题的段落合并。例子、具体店名、偏出题干的主体不写。
  5. 高频评价词改写成规范说法，不把美誉原句当总括。
  1. 做法可以是原因，不要只找“因为”。
  2. 三类原因都算点，不漏动词类。
  3. 同话题合并，主体不能偷换。

概括作用 展开

认出：作用、意义、发挥了什么作用。正面是作用，负面是危害。

  1. 先锁定题干问的那个人或那类人，材料里没出现这个主体就不出点。
  2. 对策多在前，写得实；影响多在后，常带“了”，写得虚。
  3. 总括找动词加事件。相同、相近的作用合并。
  4. 首尾都没点出主体时，准用段中高频的规范词。
  5. “优化营商环境”这类中观双性词，一点不到40字就不单列。
  1. 主体必须在，缺主体的空话不写。
  2. 对策与影响分开，影响不替代做法。
  3. 按词得分，保留规范表述。

概括综合 展开

认出：体现在哪些方面；或“做法及其成效，用一段话归纳”。要素不只有一种。

  1. 不预设是对策还是成效。内容能代回题干、说得圆，就是点。
  2. 背景、题干主体没出现的段落，不出点。
  3. 上级或其他主体的做法，不是本题对象的做法，不写。
  4. 题干写“用一段话”：不写序号，不用总括词单列，分号把做法和成效放进同一段。
  5. 例子只作解释。段里已有规范表述，留规范表述。
  1. 能回扣题干才算一点。
  2. 一段话题不另起总括、不写序号。
  3. 做法和成效都要在，例子不占点。

词句理解 展开

认出：谈谈这句话的意思、为什么这么说、对某一执法模式的理解和认识。笔记标为国省考里较难、容易压分的题。

  1. 先判断：单句；双句要拆开两边；几个分句意思相同仍按单句。多句口诀：摘掉老帽子，改变老样子，留住好根子。
  2. 释义从宏观入手，用材料里的总括词把原句换说一遍，和原句逐截对应。
  3. 分析只写这句话牵出来的要素，笔记点明多半是原因。
  4. 总结：材料有写就写，没写不写。
  5. 问“理解和认识”时，表态只三选一：支持、反对、辩证。再释义、再分析。
  1. 释义用材料总括词，不另造一套说法。
  2. 分析落在这句话涉及的原因或要素上。
  3. 相同的词要核对是不是同一件事，不是就不能合并。

启示分析 展开

认出：对我们有哪些启示。笔记定义：启示就是对策，写动词加事情。抄的是兄弟单位的做法。

  1. 当地原来的老做法、老物件，不是启示。
  2. 故事只为引出后面的做法，故事本身不写。
  3. 以前的问题可以留下当对照，做法写现在怎么做。
  4. 高频词当大哥。领导讲话可以作总领。
  5. 前后都没有规范表述时，才从故事里提动词加事情。字数宽可以加总括词。
  1. 启示写成可照做的对策。
  2. 兄弟单位的做法才算，老做法不算。
  3. 规范表述优先于故事。

变化分析 展开

认出：发生了哪些变化、结合几个台阶谈变化。问的是方式怎么变，不是把每个台阶复述一遍。属于对策类，写动词加事情。

  1. 每点都写成“变化前 → 变化后”。
  2. 题干若点明台阶数，点数大致跟着走。笔记按15分、300字估约4点，每点70字上下。
  3. 背景、倒叙引出的段落不出点。转折后面才是变化后。
  4. 书名、文件名留类别，不展开解释。
  5. 同一阶段里的检查、颁证，是变化后的做法，不要写成变化前。
  1. 必须成对：从什么到什么。
  2. 写执法方式的变化，不写人物故事。
  3. 有书名、文件名就保留类别词。

复合对策 展开

认出：梳理问题并提出建议；阐述原因并提出下一步建议。单一对策只写对策。复合对策要同时写问题和对策。

  1. 先写完所有问题或原因，再写建议。一条建议对一个问题。
  2. 对策三条路：材料里已有办法就摘抄；只有问题就反推；有成功案例或失败教训就从案例里提。
  3. 段首段尾没出现“面临的问题”，只是背景故事，不写。
  4. 调研过程不是问题，后面的困难才是。两段都有规范表述就都留。
  5. 建议允许写具体做法。笔记写明：对策要有细节、写得出可行性。
  1. 问题全，而且先写完。
  2. 建议针对该问题，可行，尽量有做法细节。
  3. 不把背景故事当成问题。

公文·措施内容 展开

认出：草拟若干措施的主要内容。要求紧扣资料、内容全面、重点突出、结构完整。

  1. 已经在做的，写成“进一步、持续推进”。今天这里做、明天那里做，也是进一步。
  2. 还是问题的，反推成下一步对策。
  3. 保留类别。有书名、引号，留核心类名。
  4. 看不出这一段在说什么，就按发言人的部门归总括。
  5. 规范词后面的例子不写。并列的三级目录只出一次点。
  1. 措施要写成下一步，不把已完成的成绩当新措施。
  2. 结构完整，重点在做法。
  3. 类别词、文件名保留。

公文·案例摘要 展开

认出：撰写案例摘要，入选典型、准备推广。突出做法，字数通常紧。

  1. 标题用“关于××的案例摘要”。称谓、结尾、落款这道题的笔记写明不用写。
  2. 开头可写背景、目的、问题、成效、过渡。主体主要是对策加影响。
  3. 成效要补上，笔记当作推广的理由。
  4. 故事性材料多用来引出；系统功能、做法、成效这类规范段才是点。两者讲同一件事时合在一起，不孤立摘故事。
  5. 空泛句、纯故事不写。
  1. 做法全，成效要有。
  2. 规范表述优先于故事。
  3. 标题点明案例，不写称谓和落款。

公文·推荐材料 展开

认出：拟写推荐材料，推荐某团队、某集体参选。要求结构完整、语言流畅。

  1. 标题用“关于推荐××的推荐材料”。称谓一般不写；字数宽裕可以配一个。
  2. 开头写这个团队承担什么、稳定运行和获得的评价。
  3. 主体写具体做法和影响。同一件事的自然段合并。
  4. 材料里的数字原样保留，不改成大约数。
  5. 框架仍是开头、主体；结尾按材料有没有号召决定，笔记没有要求另编空话。
  1. 推荐对象和职责要清楚。
  2. 做法加成效，数字不改。
  3. 结构完整，不靠故事凑字。

公文·汇报提纲 展开

认出：汇报提纲。题干常指定几个案例，并要求基本情况、执法过程、处理结果。

  1. 标题用“关于××的汇报提纲”。笔记写明提纲类不写落款，称谓也不写。
  2. 一个案例一块。每块按基本情况、执法过程、处理结果。
  3. 基本情况写问题和指向；过程写检查、解释、认定；结果写处罚、退款、改条款。
  4. 法律定性、格式条款这类规范句要留在后面。同一案例里的重复细节不单列。
  5. 字数紧就把语言压短，三个案例都要到，不展开例子。
  1. 题干点名的三块都写全。
  2. 每个案例过程和处理结果都在。
  3. 提纲不写落款。

公文·简报 展开

认出：写一份简报，梳理变化轨迹、介绍现在的状况。笔记标成变化分析类题目。

  1. 题干给了标题就照抄。称谓不写。题干没指定落款单位，笔记写明落款不写。
  2. 按连续轨迹写：过去是旧状态，中间是对策和成效，现在是现在的状况。
  3. 轨迹不能跳站。笔记比喻：火车从起点到终点，中间站都要经过。
  4. 开头短，直接进入变化，不把全国背景写长。
  5. 文学性形容、过细的个数不写。相近的空话合并，保留后面更具体的。
  1. 标题照抄。
  2. 过去、变化、现在连得上。
  3. 做法和结果都有，不写空泛形容。

公文·发布词 展开

认出：拟写发布词，呼吁报名。要求宗旨明确、介绍全面、有号召力。笔记标为非常规公文。

  1. 标题可以写成“××发布词”，笔记允许删掉“关于”和“的”。
  2. 落款写发布单位和日期。
  3. 开头写目的、定义和影响。主体写这批项目是什么、怎么参与、能带来什么。
  4. 例子不写。总括性、规范性的句子要写，并落到号召。
  5. 题干年份以外、已经发布过的旧项目，不写成这次发布的内容。
  1. 宗旨和号召要在。
  2. 项目介绍用规范表述，不靠人物故事。
  3. 标题、单位、日期齐全。

公文·宣传稿 展开

认出：为公众号写宣传稿、文案。笔记写：最好标题个性化一些。300字偏紧。

  1. 标题写成一句文案，不写成“关于……的宣传稿”。
  2. 称谓不写。落款不写，笔记理由是读者知道这是哪个单位的号。
  3. 开头用总括。主体按领域分点，写做法。
  4. 同一主体的段落合并。后面已有规范表述时，前面的跟班故事不写。
  5. 300字只留总括和做法，不展开情节。
  1. 标题像文案，点题。
  2. 内容是做法，条理按领域分。
  3. 故事段不占字数。

大作文 展开

认出：讲义未展开。目录后只有五类话题的高分样卷，没有大作文题干。

  1. 讲义未给出审题步骤。
  2. 讲义未给出结构模板。
  3. 个人笔记停在宣传稿，没有大作文复盘。
  1. 不把范文句子当成踩分点。
  2. 不补讲义里没有的写法。
  3. 只记住话题分五类：经济、政治、文化、社会、生态。

概括对策

空白讲义用三道题练同一题型：幼有善育的做法、信用修复的做法、高空抛物治理的做法。方法相同，不分成三套。

怎么认出这道题

题干是“概括主要做法、主要措施”。笔记的审题链是：范围 → 做法 → 对策 → 重点落在动词加事件。主体必须是题干里的那一方。问“各地”，国家层面的段落不是各地的做法。问公安机关，法院的做法不写。时态只收完成时和现在时。

解题思路

  1. 审题圈定范围、主体、字数，并算出大约几点。
  2. 粗读定前置词：看首尾句、高频词、关联词、主体，先分出总与分，不在粗读上耗完时间。
  3. 精读时，规范表述优先；不规范的说法才转成规范说法。
  4. 故事里没有规范句，就抽动词加事情；已经有总括句，例子就丢掉。
  5. 定总括词：优先用能罩住并列做法的那个词。并列的几件小事不能硬举一件当总括。选不出，就把问题反推成对策。总括不能偏大偏虚。
  6. 按“总括词。做法，做法。”写成独立的一条。相同、相似、高频的点合并。

踩分要点

  1. 全面：一个都不少，宁滥勿缺，按词得分。
  2. 准确：原词原句优先。阅卷按点给分，尽量用材料里的词，不换成更“高大上”的说法。
  3. 条理：前置词独立成条。一条里分得清总括和做法。
  4. 层级：一级是总括，二级是关键词，三级是细节。字数紧时留一、二级。

注：开篇作答原则现作“宁滥勿缺”。早先一页曾印成“宁滥切缺”，勘误说明和改后笔记都以“宁滥勿缺”为准。第9页手写有一句相反的字数口诀，辨认不稳定，这里不采用。

答题结构

先一句总括，再分条。不必加公文标题。笔记旁虽有“标题怎么定”，参考答案本身没有标题，概括题不把标题当必写项。

某某坚持……模式，构建……体系。

1.总括词。具体做法，具体做法。

2.总括词。具体做法。

容易丢分的地方

  • 带“将、未来、接下来、待模式成熟后”的内容，一律不写。
  • 群众案例、某一个园所或企业的细节，不写，不得分。
  • 材料没写的投入、法规，不补。
  • 只写影响、成效、总括性的结果，没有做法，不单列。
  • 偷换主体。段里没有题干主体，整段不精读。
  • 双引号里的解释可以不写。递进关系留后面更具体的说法。
  • 超字数直接扣。先删修饰，保核心点。300字可以把做法写全；200字可以把“依托、根据”省掉。
  • 300字宁滥勿缺是“点要全”，不是把故事和虚词都堆进去。

考前口诀

审主体，找做法，总括罩住并列项；将和未来一律不写，原词按点给分。

概括问题

讲义练习是简述微短剧市场的乱象。空白讲义没有另写一套问题题方法，下面是这道题笔记里的口径。

怎么认出这道题

题干出现乱象、问题、不足，或要求简述负面情况。要写消极表述。材料前部若是正面评价，笔记按背景处理。

解题思路

  1. 先按概括题的粗读、精读走一遍，要素顺序里优先找问题。
  2. 只收消极事实：价值导向偏差、保护模式缺失、虚假宣传、维权困难、盗版抄袭。
  3. 有规范表述就用规范表述。没有规范句的故事，才从故事里找问题。
  4. 段与段都在讲同一件困难，才合并。一个段里既有这个问题、又岔到另一个问题，要拆开。
  5. 监管部门后来的整治、行业变好的成效，不是乱象，不写。

踩分要点

  1. 问题本身全，消极词准确。
  2. 原词优先，不把对策写进问题。
  3. 不同问题分开，相同问题合并。

答题结构

1.总括词。消极事实，消极事实。

2.总括词。消极事实。

不写“应当如何治理”。

容易丢分的地方

  • 把开头的正面愿景写成一点。
  • 把“加强监管、坚持内容为王”这类对策或成效写成乱象。
  • 故事前后有交叉，就整段并进上一个点。
  • 既能理解成问题、又能理解成结果的句子，字数不够时还硬单列。
  • 15分、200字偏紧，一点大约40字，只留问题，不讲故事。

考前口诀

问题题只收乱象，对策成效都不是点；不是同一个困难，就不要并。

概括原因

讲义练习是分析某县能够做好绿色发展的原因。笔记对这一类的总判断写在题旁。

怎么认出这道题

题干是“分析原因、为什么能够做成”。笔记写明：概括原因类题目，绝大多数是在找对策。

解题思路

  1. 原因按三块找：对策，也就是动词；形容词，也就是条件和长处；成果影响。
  2. 句子若能直接回答“为什么做成了”，就代入答案，往题干的目标上靠。
  3. 同一做法既能看成对策、也能看成结果，只要是原因就保留。
  4. 背景句、双引号里解不开的感慨，不出点。后面有规范表述，就留规范表述。
  5. 同一话题跨段出现，合并成一个点。高频评价改写成规范词，再当总括。

踩分要点

  1. 做法类原因不能漏，这是笔记认定的大头。
  2. 条件、成果两类也要，不只写动词。
  3. 主体是题干里的那个县或那一方，企业个例和民宿数量这类三级例子不写。

答题结构

1.总括词。做了什么，所以能够做成。

2.总括词。具备什么条件。

3.总括词。带来什么结果，反过来说成原因。

容易丢分的地方

  • 只找“因为、由于”，把整段做法丢掉。
  • 总括写得比材料大。材料只铺开了户外旅游，就不能写成空泛的“完善全部产业”。
  • 把某一个企业、某一个项目的名字当成独立要点。
  • 250字、大约5点时每点约50字，可以写做法，不必压成40字。
  • 题干主体以外的主体，笔记标为偷换，不写。

考前口诀

原因题大多在抄做法；动词、长处、结果，三类都能成原因。

概括作用

讲义练习是概括人才在乡村振兴中发挥的作用。空白讲义没有单独的作用题条文，步骤在笔记批注里。

怎么认出这道题

题干问作用、意义、发挥了什么作用。正面写作用，负面才写危害。要素里会同时出现对策、原因、问题，但得分点是作用。

解题思路

  1. 先找到题干点名的主体。这一段没有这个人，就不是他的作用。
  2. 区分实和虚：对策、完善制度写得实，多在前面；影响、实现某种局面写得虚，多在后面，常有“了”。
  3. 总括用动词加事件。相同作用合并，加动词合成一条。
  4. 首尾都没出现主体时，允许沿用段里的高频规范词，例如基层治理。
  5. 中观的双性词，一点写不满40字就不单列；字数宽松再考虑写。

踩分要点

  1. 每条都能回答“这个主体起了什么作用”。
  2. 规范词优先。例子里的人物故事不单独成点。
  3. 作用和做法不要混成一句话后把作用丢了。

答题结构

1.作用总括。谁做了什么，从而起到什么作用。

2.作用总括。做了什么。

200字重点写作用。题干若是“各类人才”并且字数更宽，笔记要求把企业家、文化工作者等写进去。

容易丢分的地方

  • 主体缺失的背景段、文件精神段，整段划掉。
  • 把“了”后面的宏大结果，写成比材料更高的空话。
  • 加工厂、网店、养殖场各写一条，笔记视为并列里的例子，要收到同一个作用下面。
  • 15分、200字，一点约40字，只留动词加事情。

考前口诀

先找人，再写他做成了什么；没有这个主体，就没有这一条作用。

概括综合

讲义有两道：一是“绿色工厂的绿体现在哪些方面”，二是做法及其成效“用一段话”归纳。都不是单一要素，所以合在这一型。第二道多一条书写限制。

怎么认出这道题

题干不限定只写做法或只写问题，而是“哪些方面”，或同时要做法和成效。出现“用一段话加以归纳”，书写方式要改。

解题思路

  1. 不先认定是对策还是成效影响。把找到的内容代回题干，能自圆其说就保留。
  2. 粗读仍看总与分。精读时，代词要回到它指的那句规范表述。
  3. 背景引入、题干主体没有出现的段落，不出点。
  4. 别的主体的做法不写。笔记在绿色工厂一题里明确：县里的支持不是绿色工厂本身的做法。
  5. 题干要求一段话：不写序号，不用一个总括词再起一行；做法和成效放在同一段里，分号断开。字数比分条题宽松。

踩分要点

  1. 点能回扣题干的那个词，例如回扣“绿”。
  2. 做法、成效该写的都写，不预先删掉其中一类。
  3. 一段话真正是一段，序号和总括词都不另起。

答题结构

分条时：1.方面。做法或表现。

一段话时：某地用某做法，达到某成效；另一地用某做法，达到某成效。

一段话里不再写“总的来说”。

容易丢分的地方

  • 先入为主，只找做法，把成效丢掉，或相反。
  • 把背景风景、人物动机写成独立要点。有总括句时，例子不写。
  • 一段话题仍写成1、2、3，或再加一个总括句。笔记写明一段话已经包括对象。
  • 200字的综合题按大约5点、每点40字估，字数紧，例子先删。
  • 引号中间的解释可以略，留下最后那句规范做法或成效。

考前口诀

不预设要素，能代回题干才算点；题干说一段话，就用分号，不起序号。

词句理解

讲义两道：解释一句原话并说明为什么这么说；谈对一种执法新模式的理解和认识。笔记把它们都放在词句理解下。

怎么认出这道题

题干引用原话，问意思、为什么这么说，或问对某个词、某种模式的理解和认识。笔记提醒：国省考里这类题较难，也容易压分。要先判断是单句、双句还是多句。几个分句意思相同，按单句处理。

解题思路

  1. 单句：整句一个意思。双句：两边都要写到。多句按笔记口诀处理：摘掉老帽子，改变老样子，留住好根子。
  2. 释义从宏观入手，用材料中的总括词把这句话换说一遍，和原句的前后截对应。
  3. 分析只写这句话牵出来的要素。笔记写的是：涉及哪些要素就写哪些，多半是原因。没发生过的旧状况用来说明“为什么能说出这句话”，不是把旧状况再评价一遍。
  4. 总结放在最后。材料有相应的句子就写，没有就不写。
  5. 题干是“理解和认识”时，先表态。笔记只给三种：支持、反对、辩证。材料整篇在肯定，就站在肯定一边，再释义、再分析。

踩分要点

  1. 释义用材料里的总括，不自拟概念。
  2. 分析落在原因和做法上，能解释“为什么这么说”。
  3. 字面相同的词要核对是不是同一件事。不是同一事，不能因为词一样就合并。

答题结构

这句话是指……（用总括词对应原句）。

之所以这么说，是因为：1.…… 2.……

材料若有收束句，最后写一句总结；没有就停。

理解和认识题：先写支持、反对或辩证中的一种，再接“是指……”，然后分点。

容易丢分的地方

  • 只把原句换几个字，没有用材料里的总括词。
  • 双句只写了一边。
  • 把与这句话无关的企业困难、背景故事写成要点。
  • 看到同一个词出现两次就合并。笔记要求先看是不是同一件事。
  • 总结材料没写，自己补一句口号。
  • “了”在字面上常是结果，释义时要回到宏观意思，不要只复述结果。

注：双句那一句手写口诀，两遍辨认不一致，页面不写死那八个字。多句口诀两次辨认相同，予以保留。

考前口诀

先释义，再写这句话牵出的原因；材料有总结才写总结，没有就不编。

启示分析

讲义练习是谈某市帮扶小微企业的做法对我们有哪些启示。空白讲义没有启示的定义，定义在笔记里。

怎么认出这道题

题干出现“启示”。笔记直接定义：启示等于对策，写动词加事情。对象是兄弟单位，不是出题当地原来就有的做法。

解题思路

  1. 把当地政府、企业原先的状态当成老物件。老物件不是做法，不写进启示。
  2. 故事、个例只为引出后文做法。三级目录的故事不写。
  3. 对比句里，以前的问题可以留下当对照，启示写现在的做法。
  4. 高频词可以当这一条的大哥。领导讲话若能罩住全篇，可以作总领。
  5. 某一段前后都没有规范表述，只能从故事里提炼动词加事情。字数宽裕时可以加总括词。

踩分要点

  1. 每条都是能照做的对策。
  2. 抄的是被帮扶、被参观的那一方的做法。
  3. 有规范表述就用规范表述，不复述故事。

答题结构

总领可以是：制定文件，采取行动，为群众办实事。

1.启示总括。具体做法，具体做法。

2.启示总括。具体做法。

容易丢分的地方

  • 把“我们以前只会种地”这类旧问题写成一条启示。
  • 把参观见闻、人物收入写成要点。
  • 题干主体和做法主体不一致时仍整段照抄。笔记会标偷换主体。
  • 有规范句还去改写故事。
  • 20分、300字笔记认为字数宽，可以写总括，但不是把例子加回去。

考前口诀

启示就是对策，抄兄弟单位正在做的事；老做法和故事都不要。

变化分析

讲义练习是结合四个台阶，谈执法方式发生了哪些变化。笔记强调问的不是台阶本身。

怎么认出这道题

题干出现“发生了哪些变化”，或要求结合发展阶段、台阶来谈。要素是变化前、变化后。笔记把它归入对策类，答案写动词加事情。

解题思路

  1. 先看题干问的是谁的方式变了。不要按材料顺序把每个年份复述成一点。
  2. 题干若写出台阶数量，用它预判点数。这道题笔记按大约4个变化点来估。
  3. 每一条都写成从过去的做法，到后来的做法。
  4. 倒叙、背景、引出下文的段落不出点。出现转折时，后面才是变化后。
  5. 文件、办法保留书名或类别。颁证、讲解、扶持是变化后的做法，不要写成变化前。

踩分要点

  1. 变化前和变化后成对出现。
  2. 写的是执法方式，动词加事情，不是人物经历。
  3. 文件名、办法名留类别，不丢。

答题结构

1.从……到……。过去怎样，后来怎样做。

2.从……到……。后来的做法，做法。

15分、300字，笔记估每点70字左右，字数相对宽，可以把变化后的做法写清楚。

容易丢分的地方

  • 按四个台阶各写一段故事，没有写成“方式的变化”。
  • 把开篇的体检报告、回忆段当成第一个变化。
  • 只写变化后，看不出从哪里变来。
  • 县、镇、县政府有没有这项权限分不清时，笔记要求不出点，不猜。
  • 结果句若没有新的做法，不单独再占一条。

考前口诀

先写从哪变到哪，再写后来的做法；台阶是线索，不是答案本身。

复合对策

讲义三道都收在提出对策里：问题加建议，平衡发展的工作建议，原因加下一步建议。笔记先分单一对策和复合对策。

怎么认出这道题

单一对策：只要求写对策。复合对策：答案要同时写出问题和对策。题干常见“梳理问题并提出对策建议”“阐述原因并提出下一步工作建议”，要求里写明先写完问题或原因，再写建议。

注：第二道的印刷要求仍是“先梳理完所有问题，再提出建议”。笔记在“提出工作建议”旁标了“单一对策”，同时又写答案必须包含问题梳理和工作建议两段。按笔记：不另起一种题型，两段都写。

解题思路

  1. 先把问题或原因写完，再写建议。建议与问题一条对一条。
  2. 已有解决方案，直接摘抄。只有问题、没有办法，按问题反推。出现成功案例或失败教训，从案例里提炼对策。
  3. 段首和段尾都没说“面临的问题”，只是在讲背景，整段不写。
  4. 调研、开会、动员本身不是问题。后面的贷款难、住房难、培训不对口，才是问题。两段都重要且后段有规范表述，就留后段；字数紧时，缺例子的那一段可以只留有规范词的要点。
  5. 原因类的复合题，用负面表述代入，找“为什么推不动”。首尾反复出现的“不理想”，笔记当成高频，要反推成对策。

踩分要点

  1. 问题或原因全面，且全部写在建议前面。
  2. 建议具体、可行、对得上那一条问题。
  3. 材料里已有的办法优先摘抄，不另造一套。

答题结构

问题：

1.问题总括。具体表现。

建议：

1.针对上述问题。做法，做法。

原因加建议时，把“问题”换成“原因”，后面仍逐条对应。

容易丢分的地方

  • 建议写在问题前面，或问题没写完就夹一条建议。
  • 把试验成功、风景介绍、政策出台的背景当成问题。
  • 问题写了，建议是空话，对不上那一条。
  • 反推时把材料里的具体周期、具体缺口全部抹掉。笔记允许把不放心、但能体现可行性的细节写进建议。
  • 理想和现实的落差若首尾都出现，不能只当口号，要收成原因并反推。

考前口诀

先问题，后建议，一条对一条；有办法就摘，没办法就反推，有案例就从案例里提。

公文写作·措施内容

讲义练习是为物流数字化草拟若干措施的主要内容。笔记没有单独改公文六件套，重点在“进一步”和结构。

怎么认出这道题

题干是草拟《若干措施》的主要内容，或拟写措施类公文的主体。要求紧扣资料、内容全面、重点突出、结构完整。笔记判断：题干已经暗示有一批做法，要在这个基础上再写下一步。

解题思路

  1. 已经在做、还要继续的，写成进一步、持续推进。两地都在做同一类事，也按进一步写。
  2. 材料转向“尚未、缺少、担忧”，这是问题，反推成下一步，不把问题本身当措施。
  3. 有书名、引号，保留类别和核心词，不改成自己的概括。
  4. 一段看不出总括时，按发言人的部门给这一条归类。
  5. 规范句后面若是举例，例子不写。几个三级目录属于同一服务体系，只出一个点。

讲义未展开

这道题的笔记没有单独规定称谓写不写、落款写不写。不要按别的文种把这两项补死。结构完整按题干要求执行：措施本身要成体系。

踩分要点

  1. 措施是下一步，不是成绩单。
  2. 点全面，重点做法突出，结构能看出几条措施。
  3. 文件名、类别词保留。

答题结构

1.总括词。进一步怎么做，怎么做。

2.总括词。针对尚未解决的问题，下一步怎么做。

已有资金、已有项目，用“持续推进”，不写成从零开始。

容易丢分的地方

  • 把“已经建成、已经获批”写成一条新措施。笔记认为那是成绩，后面的“下一步”才是措施。
  • 问题段只抄困难，没有反推做法。
  • 一个例子写成一个点，前面的规范词反而丢了。
  • 总括空泛，看不出是哪一个部门的哪一类事。
  • 超400字。先删例子和成绩，留进一步的做法。

考前口诀

正在做的写进一步，还没做的按问题反推；类别词留下，例子删掉。

公文写作·案例摘要

讲义练习是为准备全省推广的基层治理案例写摘要。笔记给了这一文种的框架。

怎么认出这道题

题干出现“案例摘要”，常伴有入选典型、向更大范围推广。要求紧扣资料、突出做法、表述准确、条理清晰。

解题思路

  1. 标题写成“关于××的案例摘要”。笔记写明称谓不用写，结尾和落款也不用写。
  2. 开头从背景、目的、影响、问题、成效里选材料有的内容作过渡。主体大约九成是对策加影响。
  3. 做法是主体。成效要补写，笔记把它当作“为什么值得推广”。
  4. 先分材料：故事多用于引出或佐证；功能、流程、成效属于规范材料，要点主要在这里。两者若围绕同一问题，合成一条，不把故事单独列成一点。
  5. 相同做法的相邻段合并。空泛句、纯叙事在字数紧时不写。

踩分要点

  1. 做法突出、全面。
  2. 成效在，能支撑“可推广”。
  3. 标题标明案例，不写称谓和落款。

答题结构

关于某某案例的案例摘要

开头：针对什么问题，建成什么。

1.做法总括。怎么做，取得什么成效。

2.做法总括。怎么做，取得什么成效。

容易丢分的地方

  • 整篇都是人物夜巡、上门办事，系统做法反而没写。
  • 只有做法，没有成效，推广的理由空了。
  • 自行加上称谓、此致敬礼或落款。
  • 同一功能拆成很多点，字数不够。
  • 350字仍然紧，笔记提醒空话可以不写。

考前口诀

摘要突出怎么做，成效用来说明为什么能推广；故事只引出，规范段才是点。

公文写作·推荐材料

讲义练习是推荐一个运维团队参选先进集体。笔记给了标题和正文骨架。

怎么认出这道题

题干是“拟写推荐材料”，对象是某个团队、集体或个人。要求紧扣资料、内容全面、结构完整、语言流畅。

解题思路

  1. 标题写成“关于推荐××的推荐材料”。有明确推荐单位时写进标题。称谓笔记写明不用写；字数到450字、500字这一档，可以配一个称谓。
  2. 开头写职责、长期怎么值守、获得过什么肯定。这是全篇的总述。
  3. 主体写关键做法和影响。讲同一件事的段落合并，例如监控和应急响应并成一条。
  4. 数字按材料抄。笔记专门提醒：30秒不要写成别的数。
  5. 不把人物心理、演练故事展开成独立要点。有规范句就留规范句。

踩分要点

  1. 推荐谁、为什么是这个集体，开头就要清楚。
  2. 做法和成效全面，数字准确。
  3. 结构完整，语言顺着写，不写成提纲碎片，除非题干要求提纲。

答题结构

关于推荐某某团队的推荐材料

开头：该团队承担什么，长期如何运行，获得什么评价。

1.做法。具体措施，具体成效。

2.做法。具体措施，具体成效。

容易丢分的地方

  • 标题写成新闻标题，看不出是推荐材料。
  • 数字四舍五入或改成“很快”。
  • 只写一次救场故事，职责和制度没写。
  • 同一能力拆成互不相关的好几条。
  • 字数紧还写称谓、套话。

考前口诀

标题写清推荐谁，开头写职责和评价；数字原样抄，故事给做法让位。

公文写作·汇报提纲

讲义练习是就三个执法案例写汇报提纲，并规定了每案要写的三块内容。

怎么认出这道题

题干出现“汇报提纲”。常指定案例数量，并写明包括基本情况、执法过程、处理结果。要求要点全面、层次分明。

解题思路

  1. 标题写成“关于××的汇报提纲”。笔记写明称谓不用写，提纲类公文不写落款。
  2. 按案例分块，不要打乱成“所有问题一段、所有处罚一段”。
  3. 每块内部按题干顺序：基本情况写投诉和问题，执法过程写检查、解释、法律认定，处理结果写罚款、退款、改正。
  4. 法律定性、格式条款、不合理规定写在该案例的后部。两个例子若说明同一个问题，细节不重复出点。
  5. 语言压短。400字要容下三个案例的三块，例子和人物对话不写。

踩分要点

  1. 三个案例都在，一块不丢。
  2. 每案的情况、过程、结果都能找到。
  3. 层次按案例分开，提纲不写落款。

答题结构

关于三个案例执法情况的汇报提纲

一、案例名称

基本情况：……

执法过程：……

处理结果：……

二、三照此。

容易丢分的地方

  • 三个案例合成一篇叙述，看不出案例边界。
  • 只有投诉，没有处理和改正。
  • 把当事人的原话写长，法律认定反而没写。
  • 自行加上落款、称谓。
  • 第二个案例里与前一案例实质相同的细节再占一条。

考前口诀

一案一块，情况、过程、结果；提纲不写落款，话要短。

公文写作·简报

讲义练习是以给定题目写简报，梳理电力蝶变轨迹并介绍现在的结构。笔记把它归到变化分析。

怎么认出这道题

题干要求“写一份简报”，常给定标题，并要求梳理轨迹、介绍现今状况。要求内容全面准确，结构合理，条理清晰，语言流畅。

解题思路

  1. 标题题干给了就照抄，不另拟。称谓不写。题干没说落款单位，笔记写明落款不写。
  2. 按轨迹写，不按散点写。过去是旧状态和问题，中间是对策与成效，现在是现在的结构。
  3. 中间环节不能跳。笔记的说法是：像火车从起点到终点，中间站都要经过。
  4. 开头要短，直接写本题的变化。全国性背景若只是引出，不展开。
  5. 文学性句子、过细的设备个数不写。意思相近的两段，保留后面更具体的做法。

踩分要点

  1. 标题与题干一致。
  2. 轨迹连续：旧状、做法、现在的状况都能对上。
  3. 语言是简报，不是抒情，做法和数据用材料原词。

答题结构

（照抄题干标题）

过去：缺电的状况。

随后：一方面怎么补，另一方面怎么转。每方面写做法和结果。

现在：结构变成什么样。

容易丢分的地方

  • 自己改标题，或加上副题。
  • 只写现在的成绩，看不出从缺到不缺的轨迹。
  • 中间只写一个方面，题干要求的“轨迹”断掉。
  • 把“磅礴”一类文学句写进简报。
  • 码头、泊位等三级细节占掉做法。

考前口诀

标题照抄，按过去、变化、现在写；中间站不许跳，空话和形容删掉。

公文写作·发布词

讲义练习是为新一年的公众参与科学项目拟写发布词，呼吁报名。笔记标为非常规公文。

怎么认出这道题

题干出现“发布词”，并要求宗旨明确、介绍全面、有号召力。身份通常是发布单位的工作人员。

解题思路

  1. 标题可以写成“××发布词”。笔记允许删去“关于”和“的”。字数宽时，标题里可以出现呼吁对象，也可以不写。
  2. 落款写发布单位和日期。这是这道题笔记明确要留的。
  3. 开头写目的：为什么发布，想形成什么氛围。定义和影响可以放在开头。
  4. 主体介绍这批项目是什么、覆盖哪些领域、公众如何参与、能得到什么。用总括性和规范句。
  5. 例子、人物故事不写。与本次发布年份无关、已经办完的项目，不写成这次要发布的内容。结尾要有报名或参与的号召。

踩分要点

  1. 宗旨清楚，读者知道要参加什么。
  2. 介绍全面，用规范表述而不是故事。
  3. 有号召，标题和落款齐全。

答题结构

某某项目发布词

开头：为了什么目的，现发布什么。

主体：项目是什么，包含哪些方面，如何参与。

结尾：诚邀谁参与。

落款：单位，日期。

容易丢分的地方

  • 写成普通消息，没有号召。
  • 用某个孩子、某个师傅的故事占掉项目介绍。
  • 把上一年已经发布的项目，写成今年发布词的措施。
  • 总括性的定义句觉得虚就删掉。笔记要求这类句子要写。
  • 漏掉单位和日期。

考前口诀

非常规公文也要有目的、介绍和号召；例子不写，总括句和落款要留。

公文写作·宣传稿

讲义练习是给市场监管部门公众号写一篇宣传稿。笔记对标题和字数的要求最明确。个人笔记的复盘到这一题结束。

怎么认出这道题

题干要求写宣传稿、公众号文案。笔记写：宣传稿最好标题个性化一些，标题本身要像文案。这道题300字，笔记标为比较紧张。

解题思路

  1. 标题写成一句能点题的话，不写“关于我市工作的宣传稿”。
  2. 称谓不写。落款不写。笔记的理由是：读者知道公众号属于哪个单位。
  3. 开头用能罩住全文的总括，例如干部深入一线、多项工作都有突破。
  4. 主体按领域分点。同一主体的相邻段合并。后面已经有规范表述时，前面的跟班、观摩不写。
  5. 300字只留总括和做法。故事性材料整段去掉。

踩分要点

  1. 标题像宣传，而不是公文通知。
  2. 内容全面，是做法，按领域能分开。
  3. 条理清楚，300字里没有故事。

答题结构

标题：一句文案，点出工作和成效。

开头：总括今年做了什么。

在某一领域，做法，做法。在另一领域，做法，做法。

不写落款。

容易丢分的地方

  • 标题写成标准红头标题。
  • 从干部下车间的故事写起，规范做法没空间。
  • 同一批“深入一线”拆成好几条。
  • 加上“某公众号编辑部”之类落款。
  • 300字还写场景、对话、人数细节。

考前口诀

标题写成一句文案，正文只留总括和做法；故事段删掉，落款不写。

大作文

讲义未展开

怎么认出这道题

空白讲义目录在宣传稿之后分五类高分样卷：经济、政治、文化、社会、生态。没有大作文题干，也没有“自拟题目、联系实际”之类的作答要求。个人笔记116页，复盘停在宣传稿，没有大作文页。

解题思路

讲义未展开。样卷是成篇范文，不是步骤。这里不从范文里倒推一套写法。

踩分要点

讲义未展开。没有阅卷给分说明，不编踩分点。

答题结构

讲义未展开。五类只是范文分类：经济、政治、文化、社会、生态。不把某一篇范文的开头、分论点写成模板。

容易丢分的地方

讲义未展开。不要把样卷里的事例当成考场必写材料。

考前口诀

这一型讲义未展开，不记口诀，也不补课外结构。
